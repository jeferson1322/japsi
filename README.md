# Site de divulgação profissional

Este projeto é uma landing page estática para apresentar o trabalho de um psicólogo.

## Como publicar

### Opção 1 — GitHub Pages
1. Suba a pasta para um repositório no GitHub.
2. Entre em Settings > Pages.
3. Escolha a branch principal e salve.
4. O site ficará disponível em uma URL do GitHub Pages.

### Opção 2 — Netlify
1. Crie uma conta no Netlify.
2. Arraste a pasta do projeto para o painel.
3. O site será publicado automaticamente.

### Opção 3 — Vercel
1. Conecte o repositório ao Vercel.
2. Escolha a pasta raiz do projeto.
3. O deploy será feito automaticamente.

## Arquivos úteis
- index.html: página principal
- favicon.svg: ícone do site
- robots.txt: instruções para mecanismos de busca
